## 👋 Sobre mim

Sou estudante de **Sistemas de Informação na UniFOA** e formado em
**Técnico em Automação Industrial pelo IFRJ**.

Meu foco é o desenvolvimento **back-end**, com JavaScript, Node.js,
Express e PostgreSQL. Aprendo construindo aplicações, conectando interfaces
a bancos de dados e entendendo as decisões por trás de cada funcionalidade.

Também estudo fundamentos de **cloud, redes e infraestrutura**, com
interesse em compreender o caminho de uma aplicação do código à publicação.

## 🚀 Projetos em destaque

### 🏙️ Resolucity

Projeto acadêmico voltado ao registro de denúncias de problemas urbanos,
aproximando a população das demandas da cidade.

**Tecnologias:** Node.js · Express · PostgreSQL

**Prática:** integração com banco de dados, organização em controllers e
repositories, sessões e consultas SQL.

---

### 🚚 Servio

Sistema em desenvolvimento para gestão de motoristas, rotas realizadas
e pagamentos.

**Tecnologias:** Node.js · Express · PostgreSQL · HTML · Tailwind CSS

**Foco do projeto:** construir funcionalidades de forma incremental,
da interface à persistência dos dados, com atenção à organização e à segurança.

---

### 👕 FRONTEIRA

Projeto de interface web para uma marca de streetwear, explorando
identidade visual e apresentação de produtos.

**Tecnologias:** HTML · Tailwind CSS · Figma

**Etapa atual:** design inicial do site. As funcionalidades de uma loja
virtual ainda não foram implementadas.
